# Industrial Vision

Программный модуль технического зрения для анализа видеопотока промышленного мобильного роботизированного комплекса.

## Технологии

- **Python 3.11** — основной язык разработки.
- **OpenCV** — обработка изображений и видео.
- **NumPy** — работа с массивами данных.
- **PyYAML** — чтение конфигураций YAML.
- **FastAPI** — создание API.
- **Uvicorn** — запуск API-сервера.
- **psutil** — мониторинг состояния системы.
- **PyTorch** — работа с нейронными сетями.
- **torchvision** — инструменты компьютерного зрения.
- **Ultralytics YOLO** — обнаружение объектов.
- **pytest** — автоматическое тестирование.

## Требования

- Python 3.11.
- Git.
- Виртуальное окружение Python.

## Установка и настройка

Клонируйте репозиторий и перейдите в каталог проекта:

```powershell
git clone https://github.com/MedveDevVV/industrial-vision.git
cd industrial-vision
```

Создайте виртуальное окружение:

```powershell
py -3.11 -m venv venv
```

Активируйте его в Windows PowerShell:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Структура проекта

- `configs/` — конфигурационные файлы приложения и наборов данных.
- `data/` — рабочие данные.
- `datasets/` — наборы данных для обучения и тестирования.
- `docs/` — документация и архитектурная схема.
- `models/` — файлы моделей.
- `scripts/` — вспомогательные скрипты.
- `src/` — исходный код приложения:
  - `capture/` — захват видеопотока;
  - `inference/` — запуск моделей и обнаружение объектов;
  - `tracking/` — отслеживание объектов;
  - `zones/` — работа с зонами;
  - `analytics/` — аналитика;
  - `events/` — обработка событий;
  - `api/` — API приложения;
  - `logging/` — журналирование;
  - `monitoring/` — мониторинг системы.
- `tests/` — автоматические тесты.
- `requirements.txt` — зависимости Python.
- `.gitignore` — исключения для Git.

## Конфигурация

Основные настройки приложения находятся в `configs/configuration.yaml`.

Настройки набора данных находятся в `configs/dataset.yaml`.

## Запуск приложения

Из корня проекта с активированным виртуальным окружением выполните:

```powershell
python -m src.main
```

На текущем этапе запускается базовая точка входа. Функциональность компьютерного зрения будет реализована в следующих этапах разработки.

## Тестирование

Для запуска автоматических тестов используйте:

```powershell
pytest
```

## Архитектура

Архитектурная схема и её исходное описание находятся в каталоге `docs/`. Основной конвейер предусматривает захват видеопотока, обнаружение и отслеживание объектов, анализ зон, обработку аналитики и формирование событий.

Проект разрабатывается поэтапно в соответствии с методическими рекомендациями.

# Industrial Vision

Программный модуль технического зрения для анализа видеопотока промышленного мобильного роботизированного комплекса.

## Технологии

- Python 3.11
- OpenCV — обработка изображений и видео
- NumPy — работа с массивами данных
- PyYAML — чтение конфигураций YAML
- FastAPI — создание API
- Uvicorn — запуск API-сервера
- psutil — мониторинг состояния системы
- pytest — тестирование

## Окружение

Для разработки используется виртуальное окружение Python `venv`, расположенное в корне проекта.

Если окружение ещё не создано, выполните:

```powershell
py -3.11 -m venv venv
```

## Установка зависимостей

В корне проекта выполните:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

Список зависимостей хранится в файле `requirements.txt`.

## Структура проекта

- `configs/` — конфигурационные файлы
- `data/` — рабочие данные
- `datasets/` — наборы данных для обучения и тестирования
- `docs/` — документация и схемы архитектуры
- `models/` — файлы моделей
- `scripts/` — вспомогательные скрипты
- `src/` — исходный код приложения
- `tests/` — автоматические тесты

## Запуск и тестирование

Команды запуска приложения и тестов будут добавлены по мере реализации соответствующих компонентов.

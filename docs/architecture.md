
# Архитектура Industrial Vision

## Назначение

Программа обрабатывает видеопоток, обнаруживает объекты,
отслеживает их перемещение и формирует аналитические данные
и события для промышленного мобильного роботизированного комплекса.

## Основной конвейер обработки

1. **Capture** — получение кадров из видеопотока.
2. **Inference** — обнаружение объектов с помощью модели компьютерного зрения.
3. **Tracking** — отслеживание объектов между кадрами.
4. **Zones** — проверка положения объектов относительно заданных зон.
5. **Analytics** — расчёт статистики и показателей.
6. **Events** — формирование событий на основе результатов обработки.

## Вспомогательные компоненты

- **API** — предоставление результатов другим компонентам системы.
- **Logging** — запись событий работы и ошибок.
- **Monitoring** — контроль состояния и производительности приложения.

## Текущий статус

Архитектура предварительная - конкретная модель,
формат входных данных и интерфейсы компонентов
будут уточнены в ходе разработки.
